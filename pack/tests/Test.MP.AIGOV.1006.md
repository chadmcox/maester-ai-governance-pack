People decide whether to trust and use an agent from its name and description, and reviewers decide whether to keep it the same way. An agent called "Test" or with no description can't be judged, and placeholder names often mean a test agent was left reachable.

#### Remediation action

Give the agent a clear, specific display name and a description of what it does and who it is for.
